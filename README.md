## Project Description

The Examination Scheduling and Result Processing System is a DBMS-based web application developed to manage examination-related information such as students, courses, examinations, faculty, examination halls, hall allocation, invigilator assignments, marks and results.

The project uses **MySQL** as the database and **Python Flask** for the web-based interface. The system supports CRUD operations and demonstrates concepts such as ER modeling, relational schema design, normalization, primary keys, foreign keys and database connectivity.
